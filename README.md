# Bells University Campus Network (2025–2030)

This repository contains the design and implementation of a hierarchical campus network for Bells University, Ota.

## Features Implemented
- VLAN-based segmentation
- Inter-VLAN routing using Layer 3 core switch
- HSRP for gateway redundancy
- OSPF routing
- DHCP with relay
- NAT for simulated internet access
- Access Control Lists (ACLs)

## Notes
Only one access switch was fully configured and tested due to time constraints. All other access switches follow the same configuration design.
